# Higgsfield → Mockup Studio: full-bleed gallery walls

Use these prompts in Higgsfield (or similar) to generate **empty-frame** mockup photos. Import into Mockup Studio → detect frames → save quads. Then pick them for Public Domain pack listings.

## Rules (all prompts)

- **Full-bleed art openings** — thin light-wood frames only; **no white mat, no gap, no passepartout**
- **10–18 frames** on one wall (dense salon / gallery hang)
- Mix of **portrait, landscape, and near-square** openings
- Neutral wall (warm off-white, soft greige, or pale plaster), soft daylight, no flash
- **No text, logos, watermarks, people, or furniture clutter** in front of frames
- Frames empty or with flat mid-gray placeholders (easier to composite over)

---

## 1. Mostly portrait salon

```
Photorealistic interior photo of a dense gallery wall: 14 thin light-oak wood picture frames hung salon-style on a warm off-white plaster wall. Most openings are portrait (taller than wide), with 2–3 small near-square frames mixed in. Every frame is full-bleed — artwork fills to the inner edge of the thin wood, no white mat, no border gap. Soft natural window light from the left, gentle shadows, shallow depth of field only on edges. Empty mid-gray placeholders inside each frame. No people, no text, no plants in front of frames. Shot straight-on, high resolution product photography.
```

## 2. Mixed jigsaw gallery

```
Photorealistic eclectic gallery wall with 16 thin light-wood frames in a tight jigsaw layout on a soft greige wall. Mix of orientations: roughly half portrait, a third landscape, and a few near-square. Frames touch almost edge-to-edge with small even gaps. Full-bleed openings only — no mats, no white borders inside frames. Soft daylight, neutral color grade, museum-shop catalog look. Mid-gray placeholder fills in every frame. No text overlays, no people, camera level and centered.
```

## 3. One large landscape + satellites

```
Photorealistic gallery wall: one large horizontal landscape thin light-wood frame centered, surrounded by 10–12 smaller satellite frames (mix of portrait and near-square) in a balanced cluster. Soft warm-white wall, gentle daylight. All frames full-bleed — art goes edge-to-edge inside thin wood moldings, absolutely no white mats or gaps. Mid-gray placeholders in every opening. Clean interior product shot, no furniture blocking frames, no text, high detail.
```

## After generation

1. Drop PNGs into Mockup Studio → **Calibrate New**
2. Run frame detection / mark quads for every opening
3. Tag orientation + save to library
4. In Print Generator → Public Domain pack finalize → **Pick mockup templates** → auto-place by aspect → optional Gallery Composer tweak → generate selected only
